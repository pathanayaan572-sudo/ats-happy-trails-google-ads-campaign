# Google Ads Capstone Project — Final Report


## Project Title


**Google Search Ads Campaign for ATS Happy Trails**


---


# 1. Executive Summary


This capstone project demonstrates the planning and setup of a Google Search Ads campaign for ATS Happy Trails, a residential real-estate project in Greater Noida West.


The campaign has been designed to generate qualified property enquiries and potential site-visit leads by targeting users with high purchase intent.


The project covers business research, market research, project research, audience research, competitor analysis, keyword research, campaign strategy, ad creation, budget planning, campaign structure and optimization.
