# Google Ads Search Campaign — ATS Happy Trails

## Capstone Project

A complete Google Ads Search Campaign planning and strategy project created for educational and practical learning purposes.

---

## Project Overview

This project demonstrates the end-to-end planning of a Google Search Ads campaign for **ATS Happy Trails**, a residential real-estate project located in Greater Noida West.

The campaign focuses on generating qualified property enquiries and potential site-visit leads through high-intent Google Search traffic.
